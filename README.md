# SUDRA

Site institucional estático da **SUDRA Technologies**: apresentação, trabalhos em screenshots, preços. **PT / EN** (em EN os preços aparecem em USD).

Sem build. Abra `index.html` no navegador ou sirva a pasta:

```bash
npx serve .
```

## Estrutura

```
index.html
css/styles.css      # tokens do Guia de Marca SUDRA
js/i18n.js           # strings PT/EN + locale + tema
js/main.js           # slides, carrosséis, preços, contato
brand/               # guia PDF + SVGs oficiais
assets/              # logos SUDRA, screenshots, favicon
```

## Marca

- Lockup: `assets/sudra-lockup-light.svg` / `sudra-lockup-dark.svg`
- Ícone: `assets/sudra-icon-light.svg` / `sudra-icon-dark.svg`
- Guia: `brand/SUDRA-Guia-de-Marca.pdf`
- Tipografia: Work Sans + JetBrains Mono
- Contato: `contato@sudra.com.br`
